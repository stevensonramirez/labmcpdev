Lab · Desarrollo de Apps con IA
Lab interactivo

Apps de Dynatrace (App Engine)
con MCP de Desarrollo

Conecta tu IDE con el MCP de desarrollo de Dynatrace y deja que la IA construya tu primera app.

Prerequisitos — tener esto listo antes de empezar
⬢
Node.js v18+
⌨
VS Code v1.102+
🤖
GitHub Copilot o chat IA en VS Code
🔑
Acceso a un ambiente Platform
1
Extensión
Instalar la extensión Dynatrace Apps
En VS Code, abre el panel de extensiones (⌘⇧X / Ctrl+Shift+X), busca "Dynatrace" e instala Dynatrace Apps. Necesitas la versión 0.35.0 o superior — esta versión incluye el MCP server automáticamente.
💡 No hay que configurar nada del MCP manualmente. La extensión lo registra por ti.
2
Proyecto
Crear el proyecto base
Abre la terminal integrada de VS Code y ejecuta:
terminal 
npx dt-app create mi-primera-app
💡 El toolkit genera un AGENTS.md automáticamente. No necesitas tocarlo — le da contexto extra a la IA sobre el proyecto.
3
Verificar
Confirmar que el MCP está activo
Abre el Command Palette (⌘⇧P / Ctrl+Shift+P) y escribe MCP: List Servers. Deberías ver dynatrace-apps en la lista con sus herramientas habilitadas.
⚠️ Si no aparece, verifica que la extensión Dynatrace Apps sea v0.35.0+ y reinicia VS Code.
4
La magia
Pedirle a la IA que construya la app
Abre el chat de tu asistente de IA en VS Code y pega este prompt:
prompt 
Usa las herramientas del MCP (dql_search, strato_get_component,
sdk_get_doc) para construir una app de análisis de logs.

Reemplaza la página de bienvenida por defecto, la app debe
cargar directo la funcionalidad. Incluye:

- Selector de rango de tiempo (5 min por defecto, 10, 30, 1h, 2h)
- Selector de límite de resultados (100 por defecto, 50, 200, 500)
- Filtro multi-selección por estado (ERROR, WARN, INFO)
- Gráfico de serie temporal de logs agrupados por estado
- Tabla paginada: timestamp, estado, servicio, contenido

Todos los controles deben afectar tanto el gráfico como la tabla.
Usa componentes de Strato.

Al terminar, haz deploy y dame el link para abrir la app.
Observa cómo la IA llama herramientas del MCP (strato_get_component, dql_search, sdk_get_doc, strato_get_usecase_details) para entender cómo armar la app correctamente con componentes reales de la plataforma.
💡 Usa un modelo capaz: Claude Sonnet 4.6 o Opus 4.6 dan los mejores resultados. GPT-4o también funciona.
5
Vista previa
Ver tu app en acción
Una vez que la IA genere los archivos, lanza el preview local:
terminal 
npx dt-app deploy --local
Se abre en el browser dentro del ambiente Dynatrace. Deberías ver algo como esto:

6
Iterar
Sigue experimentando
Ahora que tienes la base, prueba pedirle cosas más complejas a la IA:
ideas de prompts 
// Detalle al hacer clic
Cuando haga clic en una fila de la tabla, abre un panel
lateral dentro de la app que muestre el registro completo
del log con todos sus atributos.

// Nueva página: métricas de servicio
Agrega una segunda página a la app con navegación entre
páginas. La nueva página debe mostrar el tiempo de respuesta
y la tasa de error por servicio, usando métricas.

// Header con contexto
Agrega un header a la app que muestre la cantidad de
problemas activos de Davis y un resumen del total de logs
por estado en el rango de tiempo seleccionado.
🔑 La IA tiene acceso a toda la documentación de Strato, SDKs y DQL a través del MCP. No necesitas saber los APIs de memoria — solo describe lo que quieres.

⬢ Verificar Node.js y npx

Verificar Node.js

Abre una terminal y ejecuta:

terminal 
node --version

Si devuelve v18.x.x o superior, estás bien.

Verificar npx

npx viene incluido con Node.js. Confirma que funciona:

terminal 
npx --version
Si no lo tienes instalado

Descárgalo desde nodejs.org — elige la versión LTS. Después de instalar, cierra y vuelve a abrir la terminal para que tome efecto, y verifica de nuevo con los comandos anteriores.

💡 Si usas Mac con Homebrew, también puedes instalarlo con brew install node
